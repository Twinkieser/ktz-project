# Документация системы: KTZ Locomotive Dispatcher

## 1. Обзор системы
**KTZ Locomotive Dispatcher** — это интеллектуальная система управления подвязками локомотивов, предназначенная для диспетчеров и операторов локомотивного парка. Система автоматизирует процесс назначения локомотивов на поезда, учитывая технические ограничения, нормы обслуживания и географическое положение.

## 2. Основные модули и функции

### 2.1. Дашборд (Dashboard)
Центральная панель управления, предоставляющая ключевые показатели эффективности (KPI):
*   **Выполнено рейсов:** Процент успешно завершенных назначений.
*   **Эффективность парка:** Средний коэффициент полезного использования локомотивов.
*   **Конфликты:** Количество обнаруженных накладок в расписании.
*   **Статус парка:** Визуализация количества локомотивов в работе, в резерве и на обслуживании.

### 2.2. Управление локомотивами (Locomotives)
Реестр всего локомотивного парка с детальной информацией:
*   **Мониторинг состояния:** Уровень топлива, песка и техническое состояние.
*   **Геолокация:** Текущая станция нахождения.
*   **Технические лимиты:** Отслеживание пробега и часов работы до следующего ТО.

### 2.3. Подвязки и планирование (Assignments)
Инструмент для создания и управления рейсами:
*   **Создание подвязки:** Выбор поезда, плеча обслуживания и локомотива.
*   **Интеллектуальные рекомендации:** Система предлагает наиболее подходящие локомотивы на основе:
    *   Соответствия модели локомотива плечу.
    *   Наличия локомотива на станции отправления.
    *   Уровня топлива и песка.
    *   Остатка ресурса до ТО.

### 2.4. График оборота (Gantt Chart)
Визуализация работы парка на временной шкале:
*   **Таймлайн:** Отображение рейсов и периодов простоя для каждого локомотива.
*   **Цветовая индикация:** 
    *   *Синий:* Плановый/активный рейс.
    *   *Красный:* Конфликт (накладка по времени).
    *   *Оранжевый:* Нарушение (недостаток топлива или просроченное ТО).
    *   *Серый:* Простой.

### 2.5. Импорт данных
Массовая загрузка данных из внешних систем через файлы XLSX/CSV:
*   Автоматическое создание новых станций, поездов и локомотивов при их отсутствии в базе.
*   Валидация данных при загрузке.

## 3. Технический стек
*   **Frontend:** React 19, TypeScript, Tailwind CSS (стилизация), Lucide (иконки), Framer Motion (анимации).
*   **Backend:** Node.js (Express), SQLite (база данных), Better-SQLite3.
*   **Библиотеки визуализации:** React Calendar Timeline (график Ганта), Recharts (графики на дашборде).

## 4. Алгоритмы проверки (Валидация)
Система автоматически проверяет каждое назначение на:
1.  **Конфликты времени:** Пересечение периодов работы одного локомотива.
2.  **Топливный баланс:** Расчет расхода топлива на основе дистанции плеча.
3.  **Технический ресурс:** Запрет на выезд при превышении лимита пробега или часов до ТО.
4.  **Технологические окна:** Учет времени на экипировку и оборот локомотива на станции.
